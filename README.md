# Errm... ARGON!

A small library providing Argon2ID hashing and verification.

## Dependencies

- Erlang/OTP 28 or higher

## How to use

Not needed, check out [test/errm_argon_tests.erl](test/errm_argon_tests.erl) for examples of it working, or simply browse the code, its quite simple.
